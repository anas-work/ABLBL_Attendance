  Real-Time Hybrid Edge Face Recognition & Attendance Monitoring Pipeline

All commands assume you are in the project root:
  cd /h3/anas/ABLBL_Attendance

================================================================================
  1. QUICK START (PRODUCTION DOCKER COMPOSE)
================================================================================

# Step 1: Build the React 18 frontend bundle
npm run build

# Step 2: Start all services (PostgreSQL + Recognition Engine over HTTPS / Port 9001)
docker compose up -d

# Step 3: Access the Live Dashboard in your browser:
#   https://localhost:9001
#   https://<your-server-ip>:9001   (e.g., https://49.206.228.75:9001)
# Note: Accept the one-time browser self-signed SSL security certificate on first load.

# Useful Docker commands:
docker compose restart recognition_engine   # Restart engine after python/config changes
docker compose logs -f recognition_engine    # View real-time container recognition logs
docker compose down                         # Stop all services


================================================================================
  2. LOCAL DEVELOPMENT (WITHOUT DOCKER)
================================================================================

# Backend setup:
pip3 install -r requirements.txt

# Run backend with HTTPS (SSL certificate for camera access):
python3 -m uvicorn src.api.app:app --host 0.0.0.0 --port 9001 --ssl-keyfile config/ssl.key --ssl-certfile config/ssl.crt

# Frontend development server (Hot Module Reloading):
npm run install:frontend
npm run dev
# Vite runs at: http://localhost:3000 (proxies /api and /captures to backend at 9001)


================================================================================
  3. HOW TO START LIVE CAMERA CAPTURE IN BROWSER
================================================================================

1. Open https://49.206.228.75:9001 (or https://localhost:9001) in Chrome / Safari.
2. Click the green "START LIVE CAPTURE" button in the video viewport.
3. Allow browser camera permission when prompted.
4. The client-side Linzaer Ultra-Light ONNX detector runs locally at 60–120 FPS.
5. When a person steps in front of the camera (face size >= 120px):
   - First time: Solid GREEN box -> CHECK-IN event logged.
   - Within 30 seconds: Stays solid GREEN -> No duplicate spam.
   - After 30 seconds: Turns ORANGE -> RE-ENTRY event logged. Subsequent matches within 30s stay ORANGE.
   - Toggle to EXIT MODE: Instantly allows CHECK-OUT (Purple) without cooldown.

================================================================================
  6. DATABASE MANAGEMENT (POSTGRESQL)
================================================================================

# Connect to PostgreSQL inside Docker:
docker exec -it attendance_postgres psql -U postgres -d attendance_db

# Query recent attendance records:
docker exec -it attendance_postgres psql -U postgres -d attendance_db \
  -c "SELECT id, employee_id, event_type, timestamp FROM attendance_events ORDER BY timestamp DESC LIMIT 20;"

# Count total logged events:
docker exec -it attendance_postgres psql -U postgres -d attendance_db \
  -c "SELECT event_type, count(*) FROM attendance_events GROUP BY event_type;"
