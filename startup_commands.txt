================================================================================
  3. LIVE CAMERA MODE — HOW IT WORKS
================================================================================

1. Open https://<server-ip>:9001 in Chrome or Edge.
2. Click "START LIVE CAPTURE" in the video panel.
3. Allow camera permission when prompted.
4. The UltraLight ONNX face detector runs in your browser at ~30 FPS
   (1/3 frame decimation — inference on every 3rd frame, tracker fills the rest).

Recognition flow for each detected face:
  a. Face must reach >= 120px (gate trigger) — far-field faces are ignored
  b. 1-second "settle delay" — person must hold still before sampling starts
  c. 5 frames are sent to the server at ~600ms intervals over 3 seconds
  d. Server runs AdaFace embedding + FAISS search on each crop
  e. First successful match → CHECK_IN (Green box) logged to DB
  f. Subsequent appearances within cooldown → stays Green, no duplicate
  g. After cooldown → RE_ENTRY (Orange box) logged
  h. EXIT MODE → CHECK_OUT (Purple box) logged

State labels shown on the bounding box:
  APPROACH CAMERA   — face too small (< 120px)
  HOLD STEADY...    — in settle delay window
  ANALYZING (x/5)   — sending crops to server
  Name [Score%]     — matched successfully (Green)
  RE-ENTRY: Name    — re-entry after cooldown (Orange)
  CHECK-OUT: Name   — exit recorded (Purple)
  ⚠️ NOT RECOGNIZED — 5 attempts failed, unknown flagged


================================================================================
  4. ANDROID APP (android_clientv6)
================================================================================

Requirements:
  - Android Studio Hedgehog or newer
  - Android SDK 35 (target), minSdk 26 (Android 8.0+)
  - Physical device or emulator with camera

Setup:
  1. Open android_clientv6/ in Android Studio
  2. Update server IP in:
       app/src/main/java/com/aimonk/attendance/network/ApiService.kt
       Change: private const val BASE_URL = "https://YOUR_SERVER_IP:9001/"
  3. Sync Gradle (uses LiteRT 1.4.0 + CameraX 1.4.0 — 16KB page-size aligned)
  4. Run on device (API 26+) or emulator

The app uses the same TFLite UltraLight model (version-RFB-320.tflite) bundled
in assets/ and the same recognition logic as the web app:
  - 1/3 frame decimation
  - 1-second settle delay
  - 5-frame controlled sampling at 600ms intervals
  - Same state labels and bounding box colors

  6. DATABASE MANAGEMENT (POSTGRESQL)
================================================================================

# Connect to PostgreSQL inside Docker:
docker exec -it attendance_postgres psql -U postgres -d attendance_db

# Query recent attendance events:
docker exec -it attendance_postgres psql -U postgres -d attendance_db \
  -c "SELECT employee_id, name, event_type, confidence, timestamp FROM attendance_events ORDER BY timestamp DESC LIMIT 20;"

# Count events by type:
docker exec -it attendance_postgres psql -U postgres -d attendance_db \
  -c "SELECT event_type, count(*) FROM attendance_events GROUP BY event_type;"

# Clear all attendance events (reset for a new day):
curl -X POST https://localhost:9001/api/attendance/flush -k

# Switch system mode (ENTRY / EXIT):
curl -X POST https://localhost:9001/api/mode -k \
  -H "Content-Type: application/json" -d '{"mode": "EXIT"}'

================================================================================
  8. TROUBLESHOOTING
================================================================================

Camera doesn't start in browser:
  → Must use HTTPS. Run with --ssl-keyfile and --ssl-certfile.
  → On Chrome: navigate to chrome://flags and enable "Insecure origins treated as secure"
    if using self-signed cert on LAN.

Photos not loading in app:
  → The Android app uses a custom SSL-trusting OkHttp client — should work with
    self-signed certs automatically.
  → Check server IP is reachable from the device (same WiFi / VPN).

AdaFace model not found (server crash on startup):
  → Download kprpe_adaface.onnx (167MB) and place at models/kprpe_adaface.onnx
  → The server will fail to start without this file.

16KB page size warning on Android 15:
  → App uses LiteRT 1.4.0 + CameraX 1.4.0 — these are 16KB page-aligned.
  → If warning persists, run Clean → Rebuild in Android Studio.

TensorRT engine errors:
  → Delete old .engine files in models/: rm models/*.engine
  → Rebuild engines: PYTHONPATH=. python3 scripts/build_engines.py
  → Engines are GPU-architecture specific — must recompile after hardware change.
